Every keystroke, on screen.

Carnac is a keystroke overlay for Windows. It shows the keys and shortcuts you press, so the people watching your talk, demo or screencast can follow along. It's also a handy way to learn your own shortcuts.

> winget install --id code52.Carnac

Keymap

Who it's for

Built for people who show their work

When you move fast on the keyboard, your audience loses track. Carnac shows each key press on screen and fades it out a few seconds later.

Presentations and live demos

People at the back of the room can see every shortcut you press, so nobody gets lost when you speed up.

Screencasts and tutorials

The overlay is on screen, so your recording captures it. Viewers can pause and copy the exact keys instead of guessing.

Learning shortcuts

Watch your own keystrokes. Seeing each shortcut labelled as you use it helps new combinations stick.

Features

Everything you need, nothing in the way

Carnac lives in the system tray. Open Preferences from the tray icon to set any of the options below.

Names your shortcuts

Recognises shortcuts from the bundled keymaps and labels them. In VS Code, Ctrl+Shift+K appears as [Delete Line].

Any screen, any corner

Pick the display and the corner, then nudge the overlay with top, bottom, left and right offsets.

Styled your way

Set the font size and color, background color, opacity, popup width and how long each popup stays on screen.

Cut the noise

Show only shortcuts listed in your keymaps, only key presses that use Ctrl, Alt or Win, or both.

Per-app filter

Enter a process filter, a regular expression such as Code|devenv, and Carnac only shows keys typed in matching apps.

Silent mode

Press Ctrl+Alt+P before you type a password and Carnac stops showing keys. Press it again to resume.

See which app

Optionally show the active app's icon next to each popup, and draw spaces as ␣ so they're easy to spot.

Never in the way

The overlay stays on top of every window, but it never takes focus or blocks your clicks.

Multi-monitor

Right screen. Right corner.

Choose any connected display in Preferences and Carnac keeps its overlay there, even when your monitors aren't lined up side by side.

  • Any connected display, shown to scale in Preferences
  • Top-left, top-right, bottom-left or bottom-right
  • Top, bottom, left and right offsets in pixels
  • Works with stacked and offset monitorsNew

Add a keymap for any app

Keymaps are small YAML files in the Keymaps folder next to Carnac.exe. Copy one, change it, and restart Carnac to load it.

  • process is the app's process name without .exe, such as Code or devenv. Leave it empty to match every app.
  • Each shortcut has a name and one or more keys.
  • Chords use commas, as in Ctrl+K,Ctrl+C.
Keymaps\my-app.yml 
group:   My App
process: myapp

shortcuts:
  - name: Command Palette
    keys:
      - Ctrl+Shift+P
  - name: Comment Selection
    keys:
      - Ctrl+K,Ctrl+C

Install

Up and running in a minute

Pick whichever installer you already use. Carnac starts in the system tray.

WinGet

Recommended

The Windows Package Manager is the quickest option on Windows 10 and 11.

> winget install --id code52.Carnac

Chocolatey

Install the carnac package from the Chocolatey community repository.

> choco install carnac

ClickOnce

Auto-updates

Installs the build published on this site. Each time Carnac starts, it checks here for a newer version and offers to update.

Download setup.exe Carnac.application

Release zip

Download the latest release from GitHub, unzip it and run Setup.exe.

Latest release
Carnac needs .NET Framework 4.5.2 or later, which Windows 10 and 11 already include. On older systems, download it from Microsoft. WinGet, Chocolatey and the release zip install the upstream Code52 release. ClickOnce installs this fork's build.
